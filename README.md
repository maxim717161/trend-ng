# trend-ng

Исследование фьючерса на натуральный газ **мини (NGM, тикеры `NR*`)** на Московской бирже: подбор окон для исследования трендовой стратегии.

- Данные: MOEX ISS, часовые свечи + дневная история (объём, ОИ) всех месячных контрактов `NR<мес><год>`. Инструмент торгуется с декабря 2024, т.е. доступно ~22 месяца.
- Комиссия брокера: **0.05% от номинала за сторону** (вход и выход считаются отдельно, ролл = закрыть + открыть). Проскальзывание не учитывается.
- Прогрев: перед каждым окном берётся **1 месяц** истории. В нём индикаторы считаются, позиция = 0, метрики не считаются.
- Окно исследования: 30 дней, шаг скана 7 дней (90 окон, перекрываются).

## Запуск

```bash
pip install -r requirements.txt
python3 trend_ng/download.py      # история -> data/raw/*.parquet
python3 trend_ng/continuous.py    # непрерывный ряд -> data/ngm_continuous_60m.parquet
cd trend_ng && python3 run_windows.py   # скан окон -> reports/
```

## Как устроено

- `trend_ng/download.py` - выгрузка через ISS (с пагинацией и ретраями).
- `trend_ng/continuous.py` - склейка. Фронт на дату выбирается по объёму за **предыдущий** день (без заглядывания вперёд), экспирация только растёт. Доходности считаются внутри контракта, так что при ролле нет ценовых разрывов (аналог ratio-adjust). 22 ролла.
- `trend_ng/windows.py` - метрики трендовости окна и набор простых трендовых стратегий (Donchian 48/120/240, EMA-кроссы 12/48, 24/96, 48/192, momentum 96/240 баров; лонг/шорт).
- Метрики трендовости считаются только по цене окна (не по PnL): ER Кауфмана на 4ч барах, R² регрессии лог-цены, чистое движение. `score` = среднее перцентильных рангов ER и R².

## Результаты

Трендовые окна (непересекающиеся, топ по `score`), PnL в долях от номинала при плече 1x, медиана по 8 стратегиям, после комиссии:

| окно | движение | ER | R² | медианный net | доля прибыльных стратегий |
|---|---|---|---|---|---|
| 2025-02-06 - 2025-03-08 | +32% | 0.24 | 0.86 | +17.5% | 75% |
| 2025-03-27 - 2025-04-26 | -29% | 0.24 | 0.94 | +17.8% | 100% |
| 2025-07-17 - 2025-08-16 | -26% | 0.30 | 0.87 | +13.2% | 100% |
| 2025-10-16 - 2025-11-15 | +26% | 0.24 | 0.89 | +7.5% | 88% |
| 2026-01-01 - 2026-01-31 | +80% | 0.34 | 0.77 | +74.3% | 100% |
| 2026-03-19 - 2026-04-18 | -18% | 0.23 | 0.86 | +1.5% | 62% |

Нетрендовые окна (ER ~0.01, R² <0.1) дают -4...-17% и 0-37% прибыльных стратегий, комиссия на таких окнах - 0.3-1.4% за месяц. Полные таблицы и графики: `reports/` (`windows_trend_top.csv`, `windows_sequential.csv`, `windows_scan.csv`, `trend_windows.png`, `window_scan.png`).

Выводы и оговорки:

1. Окна, выбранные по ER/R², действительно торгуются трендовой логикой (Spearman ER vs медианный net = 0.63). Но это отбор задним числом, и 90 окон перекрываются на ~75%, поэтому значимость корреляции завышена.
2. **Месяц прогрева не предсказывает следующее окно**: Spearman(ER прогрева, ER окна) = -0.32. Для газа тренд-режим скорее сменяется боковиком, чем продолжается. Для живой торговли нужен другой ex-ante фильтр режима, этот результат его не даёт.
3. Из 18 последовательных месячных окон трендовых стратегий с положительным медианным net было 7. Один месяц (январь 2026, +80%) даёт значительную часть всей прибыли. Для выводов о стратегии нужен перебор параметров и проверка вне выборки.
4. Результаты в USD-ценах контракта. Пересчёт в рубли (курс) и размер гарантийного обеспечения не учитывались.
5. Ролл происходит по объёму, у части контрактов 2025 года это день после экспирации. Ролл на этом интервале не моделируется более аккуратно.
